# rafao — portfolio

Portfolio pessoal de **rafao**, produtor musical, DJ, sound designer e engenheiro de áudio.

Feito com HTML + CSS puro (sem build), hospedado no [Neocities](https://neocities.org).

## Estrutura

Cada seção é uma página própria, com uma lista de seções fixa à esquerda:

| Página | Conteúdo |
| --- | --- |
| `index.html` | capa e atalhos |
| `perfil.html` | fotos, bio e ficha |
| `lancamentos.html` | lançamento em destaque, player e últimos lançamentos |
| `catalogo.html` | 14 lançamentos agrupados por ano (2020–2026) |
| `colaboracoes.html` | participações em coletâneas e compilações |
| `selo.html` | Bloodworm Trax, catálogo do selo e DJ Aurous |
| `contato.html` | links de contato |
| `synths.html` | projetos de áudio e programação: Opcoda e MiniSynth32 |

```
css/site.css    estilos do site (layout, tipografia, componentes)
js/main.js      reveal on scroll
img/            capturas de tela dos projetos
```
